# FALAK — Landing Page

Sleek, interactive landing page for FALAK, a freelance studio offering custom websites, with AI video generation and automation coming soon.

## Files
- `index.html` — the whole site (HTML, CSS and JS in one file)
- `favicon.svg` — browser tab icon

## Run locally
Open `index.html` in any browser. No build step needed.

## Deploy
Hosted on Netlify from this repo. Leave the build command empty and publish the root directory. Every push to `main` redeploys.
